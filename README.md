# Talked Out of It? How Rule Violation Between Trading Agents Changes Along a Persuasion Ladder

Code, episode logs and analysis for a Swarm Alignment Hackathon project (Apart Research, November 2026,
Track 4: Multi-Agent Oversight and Control). Author: Ruiyang Wang (UNSW Sydney).

Two LLM trading agents work at a fictional FX desk. The persuader ("Atlas") has already profited from an
unverifiable tip; the target ("Birch") is behind its quarterly target. They chat for five rounds, then Birch acts
through logged tools (read files, get prices, trade, agree to a profit split, report to compliance). We add one
element of persuasion at a time (a persuasion ladder) and vary where the tip comes from. The outcome is whether
Birch shorts USD/JPY, i.e. trades on the tip.

The report is [`REPORT.md`](REPORT.md) (Figure 1: [`figures/fig_main.png`](figures/fig_main.png)).

No real trading, real persons or real non-public information are involved.

## Layout

| Path | What it is |
|---|---|
| `REPORT.md` | The report (Markdown) |
| `figures/fig_main.png` | Figure 1, generated by `hackathon_fx/make_figures.py` |
| `hackathon_fx/scenario.py` | All prompts: environment, rules, desk files, persuader conditions and variants |
| `hackathon_fx/episode.py` | One episode: chat phase, decision phase, tools, outcome coding |
| `hackathon_fx/judge.py` | LLM judge that labels each persuader message (disclose / hint / ask / split / threat ...) |
| `hackathon_fx/llm.py` | OpenAI-compatible client with provider pinning, reasoning settings and cost logging |
| `hackathon_fx/run.py` | Runs N episodes per condition; writes `runs/<time>_<target>_by_<persuader>_<tag>/` |
| `hackathon_fx/final_tables.py` | Builds every table from the logs → `hackathon_fx/final.md` |
| `hackathon_fx/make_figures.py` | Builds Figure 1 from the logs |
| `hackathon_fx/classify_reasoning.py` | LLM labels for reasoning traces (descriptive only) |
| `hackathon_fx/rerun_*.sh` | The exact commands used for each batch of runs |
| `hackathon_fx/runs/` | All episode logs (`episodes.jsonl`, `config.json`, `summary.txt` per run) |
| `hackathon_fx/data/prices_daily.csv` | Daily ECB reference rates for five FX pairs, 1 April – 20 June 2025 (see Data source) |

`final.md` and several other generated summaries (`analysis.md`, `compare*.md`, `methods.md`, `reasoning*.md`)
are written in Chinese; the numbers are the same as in the report.

## Reproduce the tables and figure (no API calls)

```bash
pip install -r requirements.txt
cd hackathon_fx
python -X utf8 final_tables.py     # writes final.md
python -X utf8 make_figures.py     # writes ../figures/fig_main.png
```

## Re-run experiments (API calls, via OpenRouter)

```bash
export PILOT_API_KEY=...            # an OpenRouter key; PILOT_BASE_URL defaults to https://openrouter.ai/api/v1
cd hackathon_fx
python run.py --mock --n 2          # no API calls
bash rerun_info.sh                  # e.g. the information-source runs (280 episodes, about USD 0.6)
```

Providers are pinned by default (`DEFAULT_PINS` in `llm.py`): DeepSeek-V4-Flash (persuader and judge) and
Llama-3.3-70B on DeepInfra fp8, Llama-4-Maverick on Parasail fp8; the persuader's reasoning is switched on
explicitly. The whole project cost about USD 16 in API calls.

## Which runs back which result

Run folders end in a tag; `final_tables.py` loads them by tag (and names the exact folders where a table uses
untagged runs).

| Report section | Conditions | Run tags (script) |
|---|---|---|
| 4.1–4.3, Table B1, Fig. 1a: persuasion ladder | `C0_earned`, `C1_disclose`, `C2a_hint`, `C2b_ask__v5` … `C2e_full__v5` | `Pabl` (`rerun_pinned.sh`, `rerun_controls.sh`) |
| 4.1, Table B2: below the ladder | `C0_earned__nochat`, `__noatlas`, `__notip`, `__pureinfo` | `Pctl` (`rerun_controls.sh`), `Pinfo` |
| 4.4, Table B3, Fig. 1b–c: tip source | `*__tell`, `*__peer`, `*__email` | `Pinfo` (`rerun_info.sh`, `rerun_info_fill.sh`), `Pemail` (`rerun_email.sh`) |
| 4.5: pressure, strict compliance | `C1_disclose__nopress`, `__strict`, `C2b_ask__nopress`, `__strict` | `Pv8` (`rerun_pinned.sh`) |
| 4.5: known alternative | `*__exit` | `Pexit`, `Xthink` (`rerun_exit.sh`) |
| 4.6: tactics | `C3a_reframe` … `C3f_urgency` | `Pv8` (`rerun_pinned.sh`) |
| 4.6, Table B4: pre-registered test | `C3a_reframe` vs `C2b_ask` | untagged 2026-11-08 14:14 runs (reasoning off), `Pconf` (`rerun_pinned.sh`) |
| App. B: persistence wording | `C2b_ask` … `C2e_full` (v7 wording) | `Pv7` (`rerun_pinned.sh`) |
| App. B: writing styles | `C4a_formal` … `C4d_emotional` | `Sty` (`rerun_provider_style.sh`) |
| App. B: stronger targets, self-play | `C0_earned`, `C1_disclose`, `C2b_ask__v5`, `C2e_full__v5` | `Pfixed`, self-play folders named in `final_tables.py` |
| App. B: reasoning traces | Gemini-2.5 with reasoning | `Rthink`, `Rthink2`, `Xthink` |

The remaining runs are kept for transparency but are not used in the report: untagged runs before
2026-11-08 14:05 (before provider pinning) and mock/smoke tests; Llama-3.3 on other pinned providers (`CW*`,
`AKpush`); a second persuader model (`QP_*`, `Q731pilot`); and an earlier combined condition (`Pv4`, `CWv4`).
Episodes that crashed on rate limits are kept in the logs with an `errors` field and excluded from all tables.

## Data source

`hackathon_fx/data/prices_daily.csv` holds the European Central Bank's euro foreign exchange reference rates
(one value per day; USD-based pairs are cross rates), retrieved through the Frankfurter API
(https://frankfurter.app). Source: ECB. These data are not covered by the licenses below; reuse follows the
ECB's terms, which require acknowledging the source.

## Provenance

All code was written during the hackathon (8–9 November 2026), except a six-line `.env` loader in `llm.py` and
two environment-variable names that follow the author's earlier pilot code. The price data were exported from the
author's earlier, unrelated forex project. Claude (Anthropic, via Claude Code) was used for coding and for wording
